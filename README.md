# Lasavo LLC

> **Yield pool savings for blockchain natives.** Your principal stays on-chain; your yield compounds automatically on **Monad** and **Coinbase Base**.

[![Netlify Status](https://api.netlify.com/api/v1/badges/8ba6972a-6267-4e28-a889-028d0d5b67b0/deploy-status)](https://app.netlify.com/projects/lasavo-yield/deploys)

- **Production Site:** [https://lasavo-yield.netlify.app](https://lasavo-yield.netlify.app)
- **Target Audience:** Blockchain-native users only (zero fiat on-ramps, non-custodial)
- **Supported Chains:** Monad & Coinbase Base

## Key Features
- **Non-Custodial Architecture:** Smart-contract-driven savings pools. Users keep custody of their own private keys.
- **Dual-Chain Yield Engine:** Capital allocated across high-throughput L1 (Monad) and institutional L2 (Coinbase Base), backed by a liquid stablecoin buffer.
- **Zero Lock-Up Period:** Withdraw principal and yield anytime without penalty.
- **Yield-Only Fee:** 10% fee strictly levied on generated yield.
